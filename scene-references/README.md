# 场景参考图库

把参考图片按竞争对手分文件夹放在这里，例如：

```
scene-references/
  竞争对手A/
    客厅01.jpg
    卧室02.png
  竞争对手B/
    暖色房间.webp
```

三个场景不限定房间类型；可全部是客厅等同类空间，按画作适配优先选择，并通过布置、家具、材质或光线区分搭配效果。

支持 JPG/JPEG、PNG、WebP。可以继续细分房间类型，也可以直接放图片。无需预先打标签。

每次生成场景前，Codex 会重新扫描全部子文件夹，结合已接受主图的配色、风格、比例、视觉密度与氛围选择参考。参考的是空间、色调、家具和光线；不复制对手画作、标志或文字。含画作的参考需要生成空墙背景，再叠加本商品主图。

图片仅保存在本地，Git 忽略图片及子目录。不要删除任务目录中的已选参考副本，它们用于追溯。图片默认不在聊天中展示。

配置：`.agents/skills/canvasra-product/scene-library.json`。更换 `root` 即可使用其他本地目录。
