## Product Studio 新任务：六张媒体（烤框 baked-frames-v1）

2026-09-11 起新任务切换为烤框流程：场景生成时把所选浮框直接画进画面，每个场景槽位只有一张图，不按框色重着色（烤进图里的框边只有几像素宽，局部改色容易伤到画面）。

| 顺序 | 槽位 | 比例与内容 | Shopify alt |
| --- | --- | --- | --- |
| 1 | master | 六比例之一，完整原画 | master |
| 2 | detail | 从主画实际裁切 | detail design visualization |
| 3–4 | scene-1 / scene-2 | 4:5，含画作与所选浮框的完整房间 | composed-framed-scene-1-v1 / composed-framed-scene-2-v1 |
| 5 | scene-3 | 4:5，大幅挂画场景 | composed-framed-scene-3-v1 |
| 6 | scene-desktop | 21:9，独立 PC 构图 | composed-framed-scene-desktop-v1 |

已有任务明确保存的 16:9 或其他历史比例保持不变，不自动重做图片。新任务保存 desktopAspectRatio=21:9；无该字段的旧任务保留原比例，已有图片不裁切或拉伸。烤框场景的画面即最终交付样式，换框不重绘场景图（历史 unframed 商品仍按归一化坐标实时叠框）。新任务不生成 texture、不提取画作坐标、不写 custom.scene_layouts；已创建商品的旧媒体保留。master 始终在 Shopify 媒体第一位供商品卡使用。移动端以 scene-3 为首图，桌面使用独立场景 hero，购买图库从 master 开始；桌面专属媒体不进入滑动图库和灯箱。

生成完整场景时输入房间参考与当前主画。当前 Studio 不进行 AI 返图审核，也不按旧审核结果自动修复；不满意时手动重做。烤框提示词要求真实浮框、画作四边完整，光照与窄接触阴影由场景成图提供；scene-1/scene-3/桌面首屏保持近正面视角，scene-2（小角落场景）允许约 30° 内的轻微侧视，但四框边必须完整可见、画作内容清晰。

主题把 composed-framed-* 场景按普通图片渲染，不再叠加第二层框；桌面 hero 与无框场景共用同一套满屏规则。每张烤框场景生成后，程序提取画作边界并测量框内画作与原作的长宽比（正面容差 10%，scene-2 侧视按透视放宽到 25%，另由模型对照原作判断画作是否被拉伸/压扁）。自 2026-09-12 起，该测量只作提示记录并写入任务记录，不再拒绝、不再停工：店主在页面上人工判断，用每张场景图下的「比例不对，重做此图」按钮重做（旧版本保留）。选择自动发布的任务一旦出现该标记，会在创建 Shopify 草稿前停在「发布前复核」，由店主确认后点「上架到 Shopify」完成发布；标记只在显式发布时清除。模型定位不出画作时仍作为程序失败停止该槽位。历史无框契约继续由主题支持：custom.scene_layouts 按 alt 保存归一化 left/top/right/bottom、sourceHash 和 composed-frames-v1 profile，主题按坐标只叠六色外框边，不重复叠主画。图库、缩略图、灯箱共享装裱事件。

发布门槛按任务类型检查在线标记：烤框任务要求 ochre-scene-frame-profile=baked-frames-v1，历史无框任务要求 composed-frames-v1（主题两个标记同时输出）。缺少对应标记时，Studio 保留已上传的草稿并进入 awaiting-theme。不能把烤框场景标为空背景，不能把本地标记当成线上已部署。

## 历史空背景契约

当前参考图传递：终选的 reason、keep、discard 按场景传入生图提示词；PC 场景使用第三张参考图的取舍要求，独立构图。前期规划读取任务保存的横竖比例和场景版本，完整场景使用生成图内光影及后续画框叠加，旧空背景保留固定挂画区域规则。已生成素材不自动重做。

这些版本继续用于旧商品、旧任务及尚未升级的 Codex 账本流程，不能静默重新解释：

| alt | 空背景挂画区（left / top / width / height） |
| --- | --- |
| scene-room-v1 | 23% / 14% / 54% / 44% |
| scene-room-large-v1 | 10% / 0% / 80% / 78% |
| scene-room-large-v2 | 18% / 18% / 64% / 44% |
| scene-room-desktop-v1 | 28% / 20% / 44% / 50% |
| scene-room-desktop-v2 | 20% / 8% / 60% / 78% |
| scene-room-desktop-v3 | 20% / 16% / 60% / 50% |

历史空背景由主题叠主画和画框；原生比例按保存任务版本确定，不从 alt 单独推断。早期三图商品与后来五至七图任务均保留。空背景不得烘焙画作、画框或残影，也不应脱离主题作为完整产品场景分发。

旧响应式任务使用 responsive-v1；空背景 v2/v3、手机 clearance-v2 需要对应在线标记。其上传前门槛与完整场景“先存草稿，再验证发布支持”的行为不同。

## 验收、替换与恢复

店主文案偏好（2026-09-09）：面向顾客的商品描述、SEO 和页面文案不写 AI 生成、AI 辅助或内部制作工具说明。使用作品预览、室内搭配示意等自然表述，保留非实拍、非比例及实际交付说明；内部生成来源和操作记录继续保留。

替换既有商品媒体前备份实际记录，仅改授权槽位；保留 ID、顺序、无关字段及发布状态。原图、裁切、参考、失败版本、映射、发布清单与回读证据都需保留。工作台实现及自动检查覆盖范围见 [Product Studio](PRODUCT_STUDIO.md)。
