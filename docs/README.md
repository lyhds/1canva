## 政策依据

## 维护方式

当前规则直接改写对应主题文档，避免在末尾不断追加互相覆盖的规定。版本差异写入媒体契约表；时点进度写项目状态并标日期、代码基线和验证范围。部署、商品更新与离线测试分别举证。任务目录、发布清单、原图和回滚备份不是可删除的文档垃圾。
